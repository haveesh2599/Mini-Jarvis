# 🤖 Mini Jarvis

A Python-based AI voice assistant powered by Gemini AI.

Mini Jarvis listens to voice commands, uses speech recognition to understand the user, connects with Gemini AI to answer questions, and can perform basic laptop automation tasks such as opening applications and websites.

## ✨ Features

- 🎙️ Voice-based interaction
- 🧠 Gemini AI-powered answers
- 🗣️ Speech recognition
- 💬 Natural language interaction
- 🌐 Open websites such as YouTube
- 💻 Open applications such as Google Chrome and Visual Studio Code
- ⚙️ Perform basic laptop automation tasks
- 🔐 Secure API key management using environment variables

## 🛠️ Technologies Used

- Python
- Google Gemini AI
- Speech Recognition
- Python-dotenv
- Windows automation
